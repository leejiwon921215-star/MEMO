# MEMO Windows download

[MEMO Windows 실행본 다운로드](https://github.com/leejiwon921215-star/MEMO/raw/refs/heads/downloads/MEMO-Windows.exe)

Windows 10/11 x64용입니다. MEMO-Windows.exe는 압축 해제 모듈과 앱을 한 파일에 묶은 개발 빌드입니다. 실행하면 임시 폴더에 앱을 풀어 MEMO.exe를 시작하고, 앱 종료 후 임시 파일을 정리합니다. 메모 데이터는 임시 폴더가 아닌 %APPDATA%\MEMO에 저장됩니다. 코드 서명이 없으며 실제 Windows 환경에서 최종 동작 확인이 필요합니다.

소스 코드: https://github.com/leejiwon921215-star/MEMO/tree/main

압축 해제 모듈은 Igor Pavlov의 공식 LZMA SDK 25.01의 7zSD.sfx입니다. SDK는 public domain입니다. 출처: https://github.com/ip7z/7zip/releases/tag/25.01

SHA256SUMS.txt에서 파일의 SHA-256을 확인할 수 있습니다.
