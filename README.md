# MEMO 1.4.0 — Windows

**[Windows ZIP 다운로드](https://github.com/leejiwon921215-star/MEMO/raw/refs/heads/downloads/MEMO-Windows-1.4.0.zip)**

[실행 파일만 다운로드](https://github.com/leejiwon921215-star/MEMO/raw/refs/heads/downloads/MEMO-Windows-1.4.0.exe)

기존 앱을 완전히 종료하고 ZIP을 모두 압축 해제한 뒤 MEMO-Windows-1.4.0.exe를 실행하세요. 기존 메모와 설정은 유지됩니다.

- 섹션 높이가 내용에 맞게 자동으로 늘고 줄어듦
- 상단·팝업·폴더 및 복사 버튼 기본값을 검정 글씨·검정 테두리·회색 배경으로 통일
- 버튼·글씨·형광색·상단·본문·팝업의 색 즐겨찾기와 최근 사용 색을 공통으로 연결
- 기존 글씨색·형광색 즐겨찾기를 합쳐서 보존 (즐겨찾기 64개, 최근 색 12개)
- 바로가기 관리 → 버튼 색상 일괄 변경: 상단과 모든 메모 본문의 버튼을 체크 후 적용, 전체 선택 및 기본색 복원
- 상단 색상 설정 → 창·팝업·선 색상 설정에서 배경·글씨·테두리 사용자 지정 및 기본색 복원
- 기존 메모, 폴더 경로, 복사 동작, 줄 간격과 사용자 지정 색 보존

브라우저 기능 검사 33개와 데이터 검증·실제 Electron 저장·복원·클립보드 등 검사 3개가 통과했습니다. 화면이 필요한 창 겹침 검사는 Linux 환경에서 건너뛰었으며 실제 Windows 실행은 최종 확인이 필요합니다. 앱은 코드 서명이 없는 개발 빌드입니다.

# MEMO 1.1.0 — Windows

[Windows 실행본 다운로드](https://github.com/leejiwon921215-star/MEMO/raw/refs/heads/downloads/MEMO-Windows-1.1.0.exe)

기존 앱을 완전히 종료한 뒤 새 파일을 실행하세요. 기존 메모는 %APPDATA%\MEMO에 그대로 유지됩니다.

- 기본 폭 520px, 최소 320px, 원하는 크기 지정과 크기 고정·재실행 시 복원
- 검정 본문과 흰 배경, 왼쪽 사이드바·큰 제목·장식 문구 제거
- 상단에 고정되는 폴더 버튼과 복사 버튼, 본문 커서 위치에도 추가 가능
- 저장된 메모의 최신 내용 또는 미리 정한 문구를 줄바꿈과 함께 클립보드에 복사
- 메모 목록·검색·즐겨찾기·백업은 상단 메뉴에서 사용

Windows 10/11 x64용 서명 없는 개발 빌드입니다. 실제 Windows의 탐색기 실행과 다른 창 위 표시는 최종 확인이 필요합니다. 브라우저 검사 15개와 실제 Electron 저장·크기 복원·클립보드·폴더 경로 검증 2개를 통과했고 디스플레이가 필요한 창 겹침 검사는 Linux 클라우드에서 건너뛰었습니다.

압축 해제 모듈은 Igor Pavlov의 공식 LZMA SDK 25.01의 공개 도메인 7zSD.sfx입니다. 실행 시 임시 폴더에 앱을 풀고 종료 후 정리하며 메모는 별도 AppData 경로에 저장됩니다.

Source: https://github.com/leejiwon921215-star/MEMO/tree/v1.1.0
